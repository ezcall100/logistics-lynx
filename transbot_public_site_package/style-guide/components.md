# Component Specs

## Buttons
- Primary (gradient), Outline, Ghost
- Sizes: sm, md, lg
- States: hover, focus-visible, disabled

## Cards
- `.card` with rounded-2xl and `shadow-card`
- Variants: KPI, Feature, Testimonial

## Navigation
- Topbar with dropdowns (Solutions, Product, Pricing, Resources, Company)
- Mobile hamburger → slide-down menu
- Global CTAs: Sign In, Sign Up, Contact

## Animations
- Use `transition-all duration-300 ease-in-out`
- `fade-in` and `slide-up` for section reveals
- Respect `prefers-reduced-motion`
