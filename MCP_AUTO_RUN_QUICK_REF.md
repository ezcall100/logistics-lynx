# Quick Reference: MCP Auto-Run

## Enable Auto-Run
1. Open AI chat (Ctrl+Alt+I)
2. Select "Agent mode" 
3. Enable "Auto-run" toggle

## Use "Keep All"
- Appears when AI suggests multiple changes
- Click "Save All" to apply all changes
- Always review diff view first
